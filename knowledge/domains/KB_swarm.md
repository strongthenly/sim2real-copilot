#### 七大代表性协同控制问题（书的主线）

两大族：**状态约束族**（收敛到某集合）与 **最优性/决策族**（求最优/均衡）。用"目标集合"统一记：

| 问题 | 目标集合 | 一句话 |
|---|---|---|
| 一致性 | 一个**点** `{c·1}` | 所有个体状态趋于同一值 |
| 编队 | 一个**仿射流形** | 一致性 + 常量期望偏移 h |
| 编队跟踪 | **时变流形** | 编队整体跟踪参考 r(t)，需观测器 |
| 合围 | 一个**凸包** `conv(leaders)` | 跟随者进多领导者凸包 |
| 编队-合围 | **分层**：领导者流形 + 其凸包 | 前两者合体，北航招牌方向 |
| 分布式优化 | `argmin Σ f_i` | 只在局部信息下最小化全局和 |
| 分布式博弈 | **纳什均衡集** | 各人最小化自己的（非合作） |

递进线：一致性 →(+h) 编队 →(+r(t)) 编队跟踪；一致性 →(+多领导者) 合围 →(与编队合体) 编队-合围；
"到达集合" →(目的升级) 分布式优化 →(非合作化) 分布式博弈。

#### 交互拓扑三矩阵（一切协同算法的最底层）

约定：**w_ij > 0 ⇔ i 能收到 j 的信息**（信息流 j→i）；W 的**每一行** = "我从谁那里收信息"。

- **W 加权邻接**：谁跟谁连、连多强。**如何得到**：0/1 = 通信半径内；加权 = 距离衰减/SNR/信任度。
- **D 入度矩阵** = `diag(W 的行和)`：`D = np.diag(W.sum(axis=1))`。派生量，一般不独立给定。
  作用：加权平均的分母（`D⁻¹W` 行随机）、入/出度判据、让 L 行和为 0。
- **L 拉普拉斯** = `D − W`：`l_ii=d_i, l_ij=-w_ij`。**网络连通性的算子**。
  性质：**行和为零** `L·1=0`；无向则对称半正定、特征值 `0=λ1≤λ2≤…`，**λ2 = 代数连通度 = 收敛速度**；
  **0 特征值重数 = 连通分量数**；含**有向生成树 ⇔ 0 单重**；左零特征向量 `ξ≥0` 决定共识值。

推导 + 真实算例（含仿真验证）见 `references/graph-matrices-and-control-law.md`；
`scripts/graph_matrices.py` 可直接跑出 W/D/L、特征值、ξ。

#### 一致性控制律解析（这本书的主干）

```
xdot_i = - SUM_j a_ij (x_i - x_j)  -  b_i (x_i - r)
          (① 邻居耦合, 相对信息)      (② 锚定/牵引)
```
- 第①项 `= -(Lx)_i`：只用相对信息。第②项：只有 `b_i>0` 的个体"知道"参考值 r。
- **"参考值对单个成员未知" = `b_i=0`**：该个体控制律里不出现 r，只靠邻居带动。
- 矩阵形式：`Xdot = -(L+B)X + B·1·rᵀ`，`B=diag(b_i)`；误差 `Edot = -(L+B)E`。
- **收敛判据**：每个连通分量**至少一个锚点**(`b_i>0`) ⇔ 存在以锚点为根的**有向生成树** ⇔ `L+B` 可逆 ⇒ 收敛到 r。
- **弹簧网直觉**：邻居间连弹簧 + 知道 r 的人被"地钉"钉在 r 上 ⇒ 整张网被拽向 r。
  等价于对势能 `V = ½Σ_{i<j} a_ij‖x_i-x_j‖² + ½Σ_i b_i‖x_i-r‖²` 做负梯度。
- **离散步长**：`ε < 2/λ_max(L+B)`，否则震荡/发散。

可跑 demo：`scripts/consensus_demo.py`（5 场景：链/环/全连/断开/无锚点，出对比图 + 动画）。

#### 常见误区 / 讲解要点

- **①项只管相对 ⇒ 整体平移自由**；②项的本质是"打破平移对称、把共同值钉到 r"。

**三、核心概念的标准解释(高频追问)**

#### "参考值对单个成员可以是未知的" = 分布式一致性跟踪

这是分布式协同最核心的思想。标准解释框架:
1. **先分两类**:①无领导一致性(收敛值由初值+拓扑自发涌现,没人预先知道);②一致性跟踪/领导-跟随(有参考值 $r$,希望全体趋于它)——"参考值对个体未知"说的是②。
2. **控制律**(讲"未知"就看 $b_i$):
   $$u_i = -\sum_{j\in\mathcal N_i} a_{ij}(x_i-x_j) - b_i(x_i-r)$$
   $b_i>0$=个体"知道"$r$; $b_i=0$=控制律里**不出现 $r$**,即"对我未知"。$b_i$ 精确对应"这个体知不知道参考值"。
3. **凭什么收敛**:靠**通信拓扑**把信息一跳一跳传过去。条件=**每个连通分量里至少有一个知道 $r$ 的成员**(有向图则是"以领导者为根的有向生成树")。哪怕只有 1 个成员知道,全群也收敛到 $r$。
4. **类比**:雁群(没人知道队形中心坐标)、排队过马路(只有排头知道去哪)、龙舟。
5. **价值**:省通信、抗单点故障、个体不需要全局信息/全局定位——**对无 GPS/依赖相对定位的 UAV 场景尤其有意义**。
6. **三种"未知"形态**:①钉扎/静态领导者(常数 $r$);②虚拟领导者/外系统(参考还在动,个体测不到→需**分布式观测器**);③完全无参考(leaderless)。
7. **前提/坑**:拓扑不满足生成树 → 分裂成几个小共识值(不到 $r$);参考在动时,收敛/跟踪快慢由 $-\!L$ 的谱($\lambda_2$)决定。

#### 交互拓扑三矩阵:W / D / L(用户会问"各有什么作用、如何得到")

**先定死约定**:$w_{ij}>0 \iff$ 信息流 $j  o i$(行 = 接收者)。约定写乱会导致 $\xi$/根/共识值全错。
| 矩阵 | 从哪来 | 管什么 | 关键性质 |
|---|---|---|---|
| $W$ 加权邻接 | 通信/感知关系**直接给定** | "谁跟谁连、多强"(结构+权重) | 对称 $\Leftrightarrow$ 无向 |
| $D$ 入度矩阵 | $W$ 的**行和**(派生,不独立给):$D=\mathrm{diag}(W\mathbf 1)$ | 归一化分母;入/出度 | $d_i=\sum_j w_{ij}$ |
| $L=D-W$ | $D,W$ 算得 | **网络连通性/收敛性** | $L\mathbf 1=0$;"图→动态系统"的桥 |

- $L$ 性质(无向):对称半正定,$0=\lambda_1\le\lambda_2\le\dots$;**0 特征值重数 = 连通分量数**;$\lambda_2>0\iff$连通,$\lambda_2$=代数连通度=**一致性收敛速度**;二次型 $v^  op L v=  frac12\sum w_{ij}(v_i-v_j)^2$(→Lyapunov/能量)。
- $L$ 性质(有向):不对称;**含生成树 $\iff$ 0 单重**;左零特征向量 $\xi\ge0$($\xi^  op L=0$)决定共识值。
- **共识值**:无向连通 = 初值平均($\xi$ 均匀);有向含生成树 = $x_{  ext{root}}(0)$(实测:入度为 0 的根恒定不动,其值传遍全群)。
- **如何得到**(工程建图流程):定节点 → 定边(通信半径) → 定方向 → 定权重(距离衰减/SNR/信任) → $D=\mathrm{diag}(W\mathbf 1)$ → $L=D-W$ → 算 $L$ 光谱判"收不收敛 / 多快 / 聚成几个"。
- 跑法:`scripts/graph_matrices.py`(无向 + 有向两个算例,直接跑出 W/D/L/特征值/ξ + 仿真印证)。

#### 7 类代表问题的"一句话 + 目标集合"(详解见 references)

| 问题 | 一句话 | 目标集合 |
|---|---|---|
| 一致性 | 全体状态趋于同一值 | 一个点 $\{c\mathbf 1\}$ |
| 编队 | 一致性 + 期望偏移 $h$ | 仿射流形(形状) |
| 编队跟踪 | 编队整体跟踪时变参考 $r(t)$(需观测器) | 时变流形 |
| 合围 | 多领导者,跟随者进其凸包 | $\mathrm{conv}(  ext{leaders})$ |
| 编队-合围 | 领导者自成编队 + 跟随者进其凸包(北航招牌) | 分层:流形 + 凸包 |
| 分布式优化 | 各人有 $f_i$,协同 $\min\sum f_i$(一致性只是手段) | $\arg\min\sum f_i$ |
| 分布式博弈 | 各人有 $J_i$,求纳什均衡(非合作) | 纳什均衡集 |

**递进主线**:几何台阶(点→流形→时变流形→凸集→分层凸集)+ 目的台阶(到达集合 → 求最优/均衡)。**两族**:状态约束族(协同控制)vs 最优性决策族(优化/博弈)。

#### 控制律的"弹簧网 / 势能"直观(讲"为什么收敛"最好用)

$u_i=-\sum_j a_{ij}(x_i-x_j)-b_i(x_i-r)$ 是二次势能 $V=  frac12\sum_{i<j}a_{ij}\|x_i-x_j\|^2+  frac12\sum_i b_i\|x_i-r\|^2$ 的**负梯度** ⇒ 等价于"**邻居间连弹簧 + 锚点钉到 $r$**",整群沿势能最速下降停在其最小值。**无锚点的分量没有"地钉"→ 只能停在自己的重心**(与 $r$ 无关)。矩阵形式 $X'=-(L+B)X+B\mathbf 1 r^  op$,误差 $E=X-\mathbf 1 r^  op$ 满足 $\dot E=-(L+B)E$。**逐项/推广/误读的完整推导见 `references/cooperative-control-notes.md`**。

#### 六、绘图 / 数值坑(实测)

- **matplotlib 中文字体**:`rcParams['font.sans-serif']=["Microsoft YaHei","SimHei"]` + `axes.unicode_minus=False`。⚠️ **Microsoft YaHei 缺 `✓`(U+2713)/`✗`(U+2717)字形**→ 图上会出乱码方框;改用文字("收敛"/"不收敛")。`★`(U+2605) 正常。
- **离散一致性仿真稳定性**:`x(k+1)=x(k)-eps*(L x + diag(b)(x-r))`,需 `eps < 2/λmax(L+B)`(全连 5 节点时 `λmax≈6`,故 `eps=0.2` 安全)。
- **步数要够**:链式拓扑 `λ2=0.081` 很小,收敛慢——**实测 eps=0.2 时要 ~1000 步才收敛到参考值**(220 步会"看着像没收敛")。判"收敛到 r"看 `max‖x_i-r‖`;判"发散/分裂"看是否停在**各连通分量的局部共识值**。
- **演示脚本见 `scripts/consensus_demo.py`**(5 场景:链/环/全连/断开/无人知道 + 对比图 + 动画)。直接 `python scripts/consensus_demo.py` 即可产出,或复制后改 `R`/拓扑/`EPS`。
