# sim-to-real 差异台账（Gap Ledger）

每个文件记录**一个**仿真与实机之间的已知差异。这是本项目最有价值的知识：模型本来就知道 PX4 怎么用，但不可能知道"我们这台机在仿真里和真机上差在哪"。

## 为什么单独成库
- 它直接决定 **sim-to-real 预测 eval** 的成绩（见 `evals/`）
- 可以做增量评估：去掉某条差异后预测误差是否上升 → 量化这条知识的价值
- trajectory 中"仿真预测 ≠ 实机结果"的地方，就是新条目的来源

## 命名
`GAP-<四位编号>-<短描述>.md`，编号只增不复用。已失效的条目不删除，状态改为 `已失效`。
