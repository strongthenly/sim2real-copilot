# 无人机集群控制入门（含《集群系统智能协同控制》映射）

## 触发
用户要从"单机自主探索"转向/兼学 **无人机集群控制 / 多智能体协同控制 / swarm**，或问某本集群教材的入门路线与"要不要理论结合实践"。

## 集群控制知识地图（4 个格子）
几乎所有集群论文/教材都落在这 4 类；把书/论文往格子里归位就不会迷路：

| 主题 | 回答什么问题 | 数学内核 |
|---|---|---|
| 一致性 / 编队 | N 个体收敛到同一状态、保持队形 | 图论(拉普拉斯矩阵 L、代数连通度 λ₂) + 一致性协议 ẋ=-Lx |
| 集群行为(swarm) | 涌现鸟群/鱼群式群体运动 | Reynolds Boids 三规则、Vicsek 模型、势函数 |
| 任务分配 / 覆盖 | 谁去哪片、怎么不重复 | 拍卖/匈牙利算法、信息增益/密度分配 |
| 通信与鲁棒 | 谁连谁、断链掉队 | 代数连通度、事件触发、拓扑切换 |

## 集群仿真 4 级台阶（摩擦从低到高）
1. **2D 质点(Python/numpy)**：验证一致性/编队算法本身，秒级迭代 —— "调算法"的沙盒，半天可成。
2. **AirSim 多机**：**本项目最低摩擦的入口** —— AirSim 原生多机(`settings.json` 多 `Vehicles`，Python `MultirotorClient(vehicle_name="Drone1/2/3")` 分别控制)，已有 AirSim+UE4.27 单机基础。
3. **PX4 多机 SITL + Gazebo**：真实飞控栈+通信；**坑多(每机独立 offboard 端口、`ROS_DOMAIN_ID` 隔离防串线)**，别入门就上，等要写论文/复现实机再付这个成本。
4. **真机(≥3 架)**：本项目只有 1 架 fouruav。

## 《集群系统智能协同控制》
- **董希旺、化永朝、任章 编著，清华大学出版社，ISBN 9787302723103**（北航任章团队；董希旺是"编队-合围控制"方向的代表人物之一）。
- **骨架(出版社内容简介原文脉络)**：**一致性控制 → 编队控制 → 编队跟踪控制 → 合围控制 → 编队-合围控制 → 分布式优化 → 分布式博弈**。
- **定位(务必先讲清)**：这是一本**控制理论教科书**(图论 + Lyapunov + 分布式协议)，**没有感知、没有任务分配、没有工程实现、没有仿真平台**，几乎无代码、无 ROS/真机内容 → 光读会"会算不会飞"，必须每读一章立刻配一个可跑仿真落地。
- 4 格映射：书的 ~70% 是"一致性/编队"格；"集群行为(Boids)"格本书**完全没有**；"任务分配/覆盖"只有"分布式优化"一章沾边且是抽象优化；"通信与鲁棒"散落在各章的拓扑假设里、无独立章。

## 理论↔实践配平表（把书每一章落成一个实验）
| 书章节 | 理论内核 | 配的实践(用本项目栈) |
|---|---|---|
| 一致性控制 | L 矩阵、ẋ=-Lx、收敛速度=λ₂ | Python 质点：N 点收敛到一起，改拓扑看 λ₂ |
| 编队控制 | 相对位置约束、编队控制律 | Python→AirSim：3 机保持三角形 |
| 编队跟踪控制 | 参考轨迹 + 编队 | AirSim：3 机编队沿圆/直线飞 |
| 合围控制 | 领导者-跟随者、凸包、多领导者 | 2 领导者 + 3 跟随者收敛进领导者凸包 |
| 编队-合围控制 | 领导者自身成编队 + 跟随者进其凸包 | 组合场景（北航招牌方向） |
| 分布式优化 | 分布式(次)梯度法 | 覆盖问题：多机分区覆盖最小化 |
| 分布式博弈 | 纳什均衡、势博弈 | 任务分配博弈(选做) |

## 补数学的最短顺序（本书所需，别跳）
线性代数(矩阵特征值) → 图论(邻接/度/拉普拉斯/连通度) → 线性系统稳定性 + Lyapunov(本书核心工具) → 凸优化基础(后两章)。
