# 协同控制全量笔记（控制律 / 图矩阵 / 7 类问题 / 推广）

> 面向"用户追问细节"时直接取用。约定：$w_{ij}>0\iff$ 信息流 $j\to i$（**行=接收者**）。

## 1. 控制律逐项推导

$$u_i=\underbrace{-\sum_{j\in\mathcal N_i}a_{ij}(x_i-x_j)}_{\text{① 邻居耦合}}\;\underbrace{-\,b_i(x_i-r)}_{\text{② 锚定(钉扎)}}$$

| 符号 | 含义 | 信息类别 |
|---|---|---|
| $x_i$ | 第 $i$ 个成员状态（位置向量） | 局部（自己有） |
| $x_j,\ j\in\mathcal N_i$ | 邻居状态 | **相对**（靠通信） |
| $a_{ij}$ | 边权（1/0，或通信质量/信任度/距离衰减） | 决定跟谁耦合 |
| $b_i$ | 是否直接知道参考值 $r$（$b_i>0$＝知道） | **绝对**信息（稀缺） |
| $r$ | 参考值（群要收敛到的目标） | 全局目标 |

- ① $x_i-x_j$ 是**相对误差**；负号 → 把 $x_i$ 拉向邻居的**加权重心**。单独存在（$b_i\equiv0$）→ 收敛到一个**自发涌现**的共同值。
- ② $x_i-r$ 是**相对参考的误差**；负号 → 把 $x_i$ 拉向 $r$。**只有 $b_i>0$ 的个体才有这一项**（"参考值对我未知" = $b_i=0$）。

**矩阵形式**：$X'=-(L+B)X+B\,\mathbf1 r^\top$，$B=\mathrm{diag}(b_i)$。
**平衡点证明**：$X^*=\mathbf1 r^\top$ 是解，因 $(L+B)\mathbf1r^\top=L\mathbf1r^\top+B\mathbf1r^\top=B\mathbf1r^\top$；唯一性 ⇔ $L+B$ 可逆 ⇔ **每个连通分量含至少一个锚点**。
**误差动力学**：$E=X-\mathbf1r^\top\Rightarrow\dot E=-(L+B)E$，指数收敛，速率 $\lambda_{\min}(L+B)$。
**离散**：$E_{k+1}=(I-\varepsilon(L+B))E_k$，稳定 ⇔ $0<\varepsilon<\dfrac{2}{\lambda_{\max}(L+B)}$（只用管稳定性，不改目标）。
**可逆性证明一句话**：$(L+B)v=0\Rightarrow v^\top(L+B)v=\sum a_{ij}(v_i-v_j)^2+\sum b_i v_i^2=0\Rightarrow v$ 在每个分量上常数且在锚点处为 0 ⇒ 每分量有锚点则 $v\equiv0$。

## 2. "弹簧网 / 势能"直观

$$V(x)=\tfrac12\sum_{i<j}a_{ij}\lVert x_i-x_j\rVert^2+\tfrac12\sum_i b_i\lVert x_i-r\rVert^2,\qquad u_i=-\partial V/\partial x_i$$
⇒ 邻居间**弹簧** + 锚点**钉到 $r$** 的二次势能负梯度，整群沿势能最速下降停在最小值。**无锚点分量无"地钉"→ 只停在自己的重心（与 $r$ 无关）**。

## 3. 图论三矩阵 W / D / L

| 矩阵 | 从哪来 | 管什么 | 关键性质 |
|---|---|---|---|
| $W$ 加权邻接 | 通信/感知关系**直接给定** | 谁跟谁连、多强 | 对称 ⇔ 无向 |
| $D$ 入度矩阵 | $W$ **行和**（派生）：$D=\mathrm{diag}(W\mathbf1)$ | 归一化分母、入/出度 | $d_i=\sum_j w_{ij}$ |
| $L=D-W$ | 算得 | 连通性/收敛性 | $L\mathbf1=0$ |

- 元素：$l_{ii}=d_i$，$l_{ij}=-w_{ij}\ (i
e j)$。
- **行和为零** $L\mathbf1=0$ ⇒ 平移不变/信息守恒。
- **无向**：$L$ 对称半正定，$0=\lambda_1\le\lambda_2\le\dots$；二次型 $v^\top Lv=\tfrac12\sum w_{ij}(v_i-v_j)^2$；**0 重数 = 连通分量数**；$\lambda_2$ = 代数连通度 = 一致性速率。
- **有向**：$L$ 不对称；**含生成树 ⇔ 0 单重**；左零特征向量 $\xi\ge0$（$\xi^\top L=0$）决定共识值。
- **共识值**：无向连通 = 初值平均；有向含生成树 = $x_{\text{root}}(0)$。
- **工程建图**：定节点 → 定边(通信半径) → 定方向 → 定权重(距离衰减/SNR/信任/交互频率) → $D=\mathrm{diag}(W\mathbf1)$ → $L=D-W$ → 算光谱判"收不收敛/多快/聚成几个"。
- 进阶：平衡图(入度=出度，$\mathbf1$ 同时是左右零特征向量)；有向生成树(0 单重)。

## 4. 7 类代表问题

| 问题 | 目标集合 | 控制律/要点 |
|---|---|---|
| 一致性 | $\{c\mathbf1\}$ | $u_i=-\sum_j a_{ij}(x_i-x_j)$；无领导值自发涌现/有领导→跟踪 |
| 编队 | 仿射流形（$x_i-x_j=\delta_{ij}$） | 一致性里 $x\to x-h$：$u_i=-\sum a_{ij}[(x_i-h_i)-(x_j-h_j)]$；位移型/距离型(刚性图) |
| 编队跟踪 | 时变流形 | 编队项 + 对 $r(t)$ 的牵引；$r(t)$ 测不到 → **分布式观测器** |
| 合围 | $\mathrm{conv}(\text{leaders})$ | 一致性项 + 对领导者（会动的锚点）的项 |
| 编队-合围 | 分层：领导者流形 + 其凸包 | 领导者先成编队，跟随者对其凸包做合围；两层耦合、时变 |
| 分布式优化 | $\arg\min\sum_i f_i$ | 各人只有 $f_i$；分布式(次)梯度/ADMM；**一致性只是手段** |
| 分布式博弈 | 纳什均衡集 | 各有 $J_i$；势博弈/一般和；**从合作到非合作** |

**递进主线**：几何台阶(点→流形→时变流形→凸集→分层凸集)+ 目的台阶(到达集合→求最优/均衡)。
**边界**：优化 = 全体最小化同一个和；博弈 = 各人最小化自己的 —— 本质分界。

## 5. 从"一条主干"推广成整本书

| 推广 | 控制律怎么变 | 对应书目 |
|---|---|---|
| 有向图 | $A$ 不对称，条件=有向生成树 | 一致性控制 |
| 二阶动力学(无人机真实模型) | 加阻尼 $-\sum a_{ij}(v_i-v_j)-b_i v_i$ | 编队控制 |
| 编队 | 引入期望偏移 $h_i$ | 编队控制 |
| 动态参考 | $r\to r(t)$，加分布式观测器 | 编队跟踪控制 |
| 合围 | 目标从点 $r$ 变成领导者凸包 | 合围控制 |
| 编队-合围 | 领导者成编队 + 跟随者进凸包 | 编队-合围控制 |
| 时延/切换拓扑 | 用 $x_j(t-\tau)$；条件=联合连通 | 通信与鲁棒 |

## 6. 常见误读清单

1. ①项只管**相对**，整体平移自由——没有②整群会漂移；②的本质=**打破平移对称、把共同值钉到 $r$**。
2. "参考值未知" ≠ 不需要参考：是**不需要人人知道**，但要**处处可传播**（拓扑条件）。
3. $\lambda_2$ 只描述**无领导一致性**速率；带锚跟踪的速率是 $\lambda_{\min}(L+B)$——别混。
4. $\varepsilon$ 只影响**稳定性/速度**，不改收敛目标。
5. 真机要加**饱和限幅**（$\tanh$ 等），否则离目标远时速度过大。

## 7. 实测数值（本机复现，可进论文/教学）

- 5 成员，$r=(4,3)$，仅 $x_0$ 知道 $r$，$\varepsilon=0.2$，1000 步：
  - 链/环/全连 → `max‖x_i-r‖ = 0.000`（λ2：0.081 / 0.139 / 0.172，**越大越快**）。
  - 断开(右组无锚点) → 右组停在自己均值 (0.75,1.5)，偏差 3.579。
  - 无人知道 → 全体停到初值均值 (0.58,0.84)，偏差 4.045。
  - 传播延迟(链式) ≈ 105→157→177→206 步（越远离锚点越慢）。
- 有向例：1→2,1→3,2→4,3→4；$L$ 特征值 0,1,1,3.5（0 单重）；$\xi=[1,0,0,0]$ → 共识值 = $x_1(0)$；仿真 $x(0)=[7,1,2,5]$ → 全 7。✅
