## 关键经验（本场景特有的坑）
1. **z 到 82m ≠ 漂移**：用户确认是真实高楼。先问环境再判异常。
2. **地面点 0.0% ≠ 建图坏**：MID360 垂直 FOV -7°~+52°，无人机装法正下方是盲区。物理正常。
3. **街道 z-spread 大 ≠ 重影**：87% 网格 >8cm 高度差是"地面+车+树冠"混叠，正常。
   - 重影只认：同层（主峰 ±0.5m 内）出现两个窄峰（间隔 5~40cm，半宽都 <20cm）
   - 修正后此图正确判"基本合格"，与人工分析一致；未修正前误判"不合格"
4. **高度层峰分布**：0m（地面）/ 2.7m / 4.9m / 11.7m 四个主峰 = 室外街道正常层结构。
5. 远点（r>66m）0.3% 聚成 109 团 = 远处真实建筑，不是散点飞点。

## 判定阈值速查
- 近处 NN 中位：<2cm 优秀 / <5cm 良好 / <10cm 偏稀 / >10cm 过稀
- 飞点 NN>1m：<0.5% 干净 / <2% 少量 / >2% 噪声明显
- 覆盖占用率：>50% 完整 / 30-50% 有空洞 / <30% 严重不足
- 主峰半宽：<25cm 平整 / 25-60cm 略厚 / >60cm 偏厚（街道场景 60cm 正常）
