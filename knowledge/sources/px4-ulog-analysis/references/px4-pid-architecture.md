# PX4 多旋翼串级 PID 架构与参数速查

> 适用：PX4 固件兼容飞控（如 nxtpx4v2 等国产仿 Pixhawk 板）。PID 算法在固件里，与硬件型号无关。
> 若地面站参数名是 `ATC_ANG_*`/`ATC_RAT_*`，则是 ArduPilot 固件——结构同为串级（姿态环 P + 角速度环 PID），名字不同。

## 1. 串级结构（4 层环）

```
期望位置 ─► [位置环 P] ─► 期望速度 ─► [速度环 PID] ─► 期望倾角/推力
                                                            │
期望姿态 ◄──────────────────────────────────────────────────┘
   │
   ▼
[姿态环 P] ─► 期望角速度 ─► [角速度环 PID] ─► 扭矩/油门 ─► 电机
```

**关键认知：不是"3 环 + 1 个多余的环"，而是"3 环核心 + 1 个只在定点模式才插电的顶层"。**

| 环 | 输入→输出 | 管什么 | 类比 |
|---|---|---|---|
| 位置环 | 位置误差→速度目标 | 离目标点差多远 | 导航员喊"开快些" |
| 速度环 | 速度误差→倾角目标 | 速度够不够 | 司机踩油门 |
| 角度环 | 角度误差→角速度目标 | 机身歪了几度 | 司机打方向盘 |
| 角速度环 | 角速度误差→扭矩 | 转得够不够快 | 方向盘助力机构 |

信息流一条流水线：差 10 米→开快点→倾斜大点→快速转过去→电机加力。每环只跟上下两环打交道。

### 模式决定哪些环在线
- **ACRO**：只有角速度环（打杆=角速度目标）
- **Stabilize 自稳**：角度环 + 角速度环
- **Altitude 定高**：垂直方向加高度/垂直速度环
- **Position/Offboard/航线**：全部 4 环（位置环此时接管"杆量→速度"解释权）
- **垂直方向同样有 4 层**：高度环(MC_POS_PZ)→垂直速度环(MC_VELZ_*)→油门

## 2. 参数作用（PX4 参数名）

### 角速度环（内环，完整 PID）
| 参数 | 作用 | 大白话 |
|---|---|---|
| `MC_ROLLRATE_P`/`MC_PITCHRATE_P` | 比例 | 转得不够快就加力；P 大→硬、跟指令快，太大→抖 |
| `MC_ROLLRATE_I`/`MC_PITCHRATE_I` | 积分 | 补长期偏差（重心偏、持续风）；太大→超调 |
| `MC_ROLLRATE_D`/`MC_PITCHRATE_D` | 微分 | 预判趋势提前刹车压振荡；太大→放大噪声高频抖 |
| `MC_YAWRATE_P/I/D` | 偏航角速度 | 偏航力矩小，D 常给 0 |
| `MC_*RATE_K` | 新版附加增益 | 一般保持默认 |
| `MC_*RATE_MAX` | 角速度限幅 | 默认 220(roll/pitch)/360(yaw) |
| `MC_*R_INT_LIM` | 积分限幅 | 默认 0.3 |

### 姿态环（外环，以 P 为主）
| 参数 | 作用 |
|---|---|
| `MC_ROLL_P`/`MC_PITCH_P` | 姿态误差→角速度指令（默认 6.5） |
| `MC_YAW_P` | 偏航姿态（默认 2.8，比横滚俯仰小） |

> PX4 姿态环基本只有 P（+FF），I≈0。积分补偿放在角速度环。

### 位置控制层（定点/航线模式）
| 参数 | 作用 |
|---|---|
| `MC_POS_P`/`MC_POS_PZ` | 位置偏差→速度指令（**只有 P**，默认 ~0.95/1.0） |
| `MC_VEL_P/I/D`(新版 MC_VEL_*) | 速度环 PID |
| `MC_ACC_FF` | 加速度前馈：按目标加速度提前给油门 |

### 前馈 FF
`MC_ROLLRATE_FF`/`MC_PITCHRATE_FF`/`MC_YAWRATE_FF`：打杆瞬间提前给力矩，不等误差累积（类比老司机预判刹车）。

## 3. 调参黄金顺序

**从内到外**：角速度环(`*RATE_P/I/D`) → 姿态环(`*_P`) → 速度环 → 位置环。
内环没调稳，动外环全白搭。

### 症状→对策表
| 症状 | 病灶 | 处理 |
|---|---|---|
| 悬停低频摇摆 | 姿态环 P 太大 / 角速度环 P 太小 | 降 `MC_*_P` / 升 `MC_*RATE_P` |
| 高频"滋滋"抖 | 角速度环 D 太大 | 降 D（或检查减震） |
| 慢慢朝一个方向飘 | 积分不足 | 升对应 `*RATE_I` |
| 刹车后过冲(点头) | D 不足 / I 过大 | 升 D / 降 I |
| 打杆反应迟钝 | 前馈不足 | 升 `*RATE_FF` |

### 默认值参考（新版 PX4，不同版本略差）
`MC_ROLL_P=6.5`、`MC_PITCH_P=6.5`、`MC_YAW_P=2.8`
`MC_ROLLRATE_P=0.15 / I=0.15 / D=0.003`
`MC_YAWRATE_P=0.2 / I=0.1`
别直接抄，按机架尺寸/重量微调。

## 4. 实测调参案例（用户 2026-08 成功案例）

| 参数 | 默认 | 用户值 | 效果 |
|---|---|---|---|
| `MC_ROLLRATE_P` | 0.15 | 0.45 | 角速度误差 RMS 0.138°/s（优秀线<1） |
| `MC_PITCHRATE_P` | 0.15 | 0.505 | 同上 0.150°/s |
| `MC_ROLLRATE_I` | 0.15 | 0.20 | 积分项最大仅 0.056（配平好） |
| `MC_PITCHRATE_D` | 0.003 | 0.005 | 无振荡（4-8Hz 能量 0.2%） |

**结论模式**：rate P 提到 ~3 倍、I 略升、D 微调——跟踪紧、无振荡、无饱和、振动正常。调参方向验证靠飞行日志（见 px4-ulog-analysis 主技能）。
