# 过度阻尼：角速度 D 过大 → 响应延迟（log_52 案例，2026-08-15）

## 现象
用户在自稳模式调角速度环 D，发现"D 越大延迟越高"。实测确认是**过度阻尼（overdamping）**，不是真延迟（信号传输滞后），是响应被阻尼"冻住"。

## 证据表（log_52，实飞仅 2.4s）
| 参数/指标 | 值 | 判读 |
|---|---|---|
| MC_PITCHRATE_D | 0.01（默认 0.003，3.3 倍） | 过度阻尼 |
| MC_ROLLRATE_D | 0.008（默认 0.003，2.7 倍） | 过度阻尼 |
| MC_PITCH_P / MC_ROLL_P | 3.8（默认 ~6.5，低 41%） | 姿态环 P 偏低 → 静差 |
| 姿态响应延迟（互相关） | roll 195ms / pitch 293ms（参考 ≤100ms） | 响应钝 |
| 姿态静差 / 到位率 | Pitch +1.23° / 0% | 姿态环 P 不足 |
| 4-8Hz 振荡能量占比 | 2.9%（<15% 安全） | 振荡已压住，代价是钝 |
| 角速度跟踪 RMS | 0.08°/s（优秀） | "锁得死"但不跟手 |
| 模式 | manual+attitude+rates = 自稳 | 位置/速度/高度环全关 |

## 机制（三层）
1. **D=减震器**：D 对误差变化率反向出力（阻尼），过大 → 阻尼"冻住"响应 → 钝/延迟感
2. **D 放大陀螺噪声**：D 越大输出里噪声占比越高 → 响应含糊
3. **IMU_DGYRO_CUTOFF（本例 20Hz）低通引入相位滞后**：D 增益越高，滤波滞后占比越大（D 想"提前刹车"，信号先被滤波拖延）

## 判读规则（可复用）
- **"延迟高/肉"先查 D 是否远超默认（0.003）** → 是 → 先降 D 砍一半，别一上来加前馈（*RATE_FF）
- **短实飞段（<5s）的延迟数字只能当方向性参考**：延迟数字 + D 参数 + 稳态静差三者互相印证才下结论
- 降 D 后振荡若回来：先查 IMU_GYRO_CUTOFF（本例 40Hz）和振荡频率，别急着把 D 加回去——D 是最后手段
- 角速度环"锁得死"（RMS 优秀）≠ 跟手：过度阻尼时跟踪误差小但响应钝，看延迟/静差而非只看 RMS

## 修复（用户执行，复飞验证）
1. MC_PITCHRATE_D 0.01→0.006、MC_ROLLRATE_D 0.008→0.005（砍约一半）
2. MC_PITCH_P / MC_ROLL_P 3.8→4.8（+1.0 步进，解静差）
3. 验证要点：小阶跃打杆看延迟是否往 150ms 内走；悬停听高频"滋滋"声（D 降太多会回来）；杆回中看是否停在原位（静差消失）

## 定制固件注意
微空 nxtpx4v2 有标准 PX4 没有的 `MC_*RATE_K` 参数（ROLL 0.35 / PITCH 0.4 / YAW 1.2），作用不明，可能参与角速度环出力/阻尼——手感异常时别排除，问微空原厂确认。
