# 定点模式持续偏移诊断:视觉yaw漂移假象 vs 机械故障真凶

2026-08-18 fouruav 实机案例(log 01_57_39.ulg,13s)。用户报"定点模式飞机一直朝一个方向偏移",最终根因是**机械振动/桨不平衡**,排查过程两轮结论被用户反证推翻,教训深刻。

## 现象
- 定点模式(POSCTL)飞行,摇杆 x/y 全程 0(没打杆),位置设定点不动
- 9.5s 开始机身被带出 1.5m、偏航 32°,用户切自稳后稳定降落

## 排查弯路(两轮被反证推翻)
1. **第一轮结论:视觉 yaw 漂移 → 污染 EKF → 定点带偏**
   - 证据:visual_odometry_aligned yaw 停在 76.8° vs 实际姿态 58.2°(差 18°,持续 3s);heading innovation 测试比 5.97>1 被拒
   - 用户反证:"之前定点没这问题"+"另一架同配置同场景没这问题"→ 一定有东西变了
2. **第二轮结论:撞到障碍物**
   - 证据:9.44s az=-15.6 / ay=-9.7 加速度冲击
   - 用户反证:"附近没有任何障碍物"
3. **最终真凶:机械振动/桨不平衡**(见下)

## 决定性证据(为什么是机械)
1. **电机分配 0.1s 突变(对角饱和)**:
   - 9.34s: M1=0.40 M2=0.33 M3=0.40 M4=0.37(四电机均衡悬停)
   - 9.44s: M1=0.06 M2=0.70 M3=0.08 M4=0.45(对角分配)
   - 9.74s: M1=0.48 M2=0.65 M3=0.00 M4=0.02(M3/M4 被打到 0)
   - 姿态环拼死抵抗**无法控制的外部扰动** = 机械
2. **姿态环打满拉不住**:tq_z=0.55(限幅 0.2 的 ~3 倍);yaw 速率指令 +89°/s 而实测 -83°/s —— 控制器指令方向与飞机运动相反 = 外部力矩远超控制力。若为估计/控制带偏,运动应跟随指令方向
3. **振动分段放大**(vehicle_acceleration RMS / gyro 峰值):
   - 4-6s: ax_rms 0.19 / wx峰 2.2 (正常)
   - 6-8s: ax_rms 1.14 / wx峰 22.8 (起飞后开始恶化)
   - 8-10s: ax_rms 1.31 / wx峰 43.8
   - 10-12s: ay_rms 2.92 / wx峰 **123.4**
   - 12-14s: 0.20 / 1.5 (停桨后恢复)
4. **failure_detector_status.imbalanced_prop_metric 27/27 样本非零(t=0 起,值=nan)** → PX4 桨不平衡检测全程报警
5. **EKF reset 计数全程无跳变**(xy_reset_counter=9 恒定)→ 无估计重置,运动连续

## 视觉 yaw 18° 偏差的定位
机械振动 → FAST-LIO 点云配准退化 → 视觉 yaw 卡错 18°。**位置 innovation 全程 <1(未被拒)只证明位置融合健康,不能排除机械**。视觉 yaw 漂是症状不是原因。

## 可复用判读规则
- **三航向源对拍**(vehicle_attitude / estimator_visual_odometry_aligned / vehicle_local_position.heading):
  - 视觉独跳、IMU 姿态稳 → 视觉估计漂移
  - 三源同步大转 + 姿态环打满拉不住 + 电机对角饱和 + 振动放大 → 机械
- **加速度冲击(az/ay 突变)≠ 撞击**:先问用户现场(障碍物?),再看振动分段和电机分配区分"单次撞击" vs "振动爆发"
- **用户反证 = 最高优先级证据**:"之前没这问题"+"另一架同配置没事"+"没有障碍物"都要求重查数据而不是坚持结论。用户对现场的把控(有无障碍/其他飞机对比)是日志之外最硬的信息
- 修复方向:停飞 → 查桨叶裂纹/缺口/变形 → 电机轴承异响/卡滞 → 桨平衡配平 → 电机座螺丝;修好机械后视觉 yaw 漂移自然消失
