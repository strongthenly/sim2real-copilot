# 高度源诊断：高度锁定 + 自稳突然爬升（log_41 实机案例，2026-08-15）

## 现象
- QGC 高度一直显示 103.8m（绝对海拔 AMSL，≈场地海拔）
- 自稳（Stabilize）模式下飞机"突然高度上升"

## 参数证据（NxtPX4v2_Copter_PX4v1.17.0.param，QGC 导出的 *.param 每行 `参数名,值`）
| 参数 | 值 | 含义 |
|---|---|---|
| EKF2_BARO_CTRL | 0 | 气压计高度融合关闭（默认1）→ EKF 绝对高度钉死开机初始值 |
| EKF2_HGT_REF | 3 | 高度首选=外部视觉（默认0=气压计）→ **空配置**（视觉没数据） |
| EKF2_EV_CTRL | 11 | "想"融合视觉（位置/速度/偏航），但实际无 ev_* 源 = 摆设 |
| SYS_HAS_GPS | 0 | 无 GPS（GPS 高度也没有） |
| EKF2_RNG_CTRL | 0 | 测距仪关闭 |
| MPC_THR_HOVER | 0.5 | 悬停油门默认值；实测悬停仅 ~0.33 → 中位油门推力过剩 |
| MPC_USE_HTE | 1 | 推力高度估计（自稳模式不用；自动模式才参与控制） |

## ulog 证据（log_41，14.4s，自稳全程 armed）
- `estimator_aid_src_fake_hgt`: fused=28/28 → **假高度源兜底**（无任何真实高度源）
- `estimator_aid_src_baro_hgt`: fused=0 → baro 融合确认关闭
- `estimator_status_flags`: `cs_fake_hgt`=100%、`cs_inertial_dead_reckoning`=100% → 纯惯性推算
- **无任何 `estimator_aid_src_ev_*` 话题** → 视觉从未进 EKF（MAVROS vision 没发/没连上）
- `hover_thrust_estimate.hover_thrust` 首=0.313 末=0.321（实际悬停油门 ~33%）

## 时间线关键点
| t | baro(真实) | EKF高度(=-z) | vz | 油门 | 俯仰/横滚 | 解读 |
|---|---|---|---|---|---|---|
| 0~4s | 102.3m | ~0 | 0 | -1.0 | 平整 | 地上；baro 绝对海拔 102~104m（QGC 的 103.8 就是它） |
| 5~9.5s | 101→105.6 | 0→1.7 | -0.3~-0.9 | -0.58→-0.46 | 平整 | 推油门爬升；**悬停点在油门≈-0.46（33%）** |
| 9.5~11.5s | 105.6→110 | 1.7→5.8 | **-3.9** | **-0.05~-0.025(近中位)** | 平整 | 杆已回中位飞机仍 3.9m/s 加速上升=中位推力过剩 |
| 11.5s | 106.6 | 5.8 | +3.35 | -1.0(拉底) | 俯仰-15°/横滚-11° | 用户压杆想降 |
| 12.5~14.1s | 102.9→103.6(**只掉3m**) | 2.2→**-9.45** | +8.7 | -1.0→0 | 俯仰-43°/横滚-47° | EKF 纯惯性高度完全失真：虚标 15m、vz 8.7m/s |

## 判读规则（可复用）
1. **baro 原始压力→换算高度 = 真实高度基准**（标准大气公式，QNH=1013.25 或 SENS_BARO_QNH）。判"真高"一律以 baro 为准，EKF 高度仅参考
2. **EKF AMSL 钉死不动 = baro 融合被关**（EKF 只在启动时用 baro 初始化一次绝对高度）。相对高度（local z）仍会变，别拿相对高度否定
3. **fake_hgt 密集融合 + cs_inertial_dead_reckoning=100% = 无真实高度源**（baro 关/GPS 无/视觉没接入）
4. **`EKF2_HGT_REF=3` + 无 `estimator_aid_src_ev_*` 话题 = 空配置**——参数写着想用视觉，实际视觉没进 EKF，别被参数骗；EV_CTRL 只是"想融合"，是否真融合以 aid_src 话题 fused 为准
5. **姿态大角度（俯仰/横滚>30°）时纯惯性 EKF 高度/vz 会被加速度积分骗飞**（实例：虚标 15m 变化 vs baro 实际 3m）
6. **自稳模式突然爬升 = 悬停油门错配**：中位杆输出≈`MPC_MANTHR_MIN+(1-MPC_MANTHR_MIN)*0.5`（0.08 时=53%）；实测悬停（hover_thrust≈0.33）远低于它 → 杆回中位持续爬升。判读法：找 vz≈0 时的手动油门杆值 = 悬停点，对比 MPC_THR_HOVER

## 修复（治本）
| 参数 | 改 | 说明 |
|---|---|---|
| EKF2_BARO_CTRL | 1 | 恢复气压计高度融合（baro 数据正常时别弃用唯一真实高度源） |
| EKF2_HGT_REF | 0 | 高度首选改回气压计（除非视觉高度真的可靠） |
| MPC_THR_HOVER | ~0.33 | = hover_thrust_estimate 实测值，让中位油门≈悬停 |

改完重启飞控生效；再飞一次下 ulog 验证高度跟手。

## 坑
- `sensor_baro` 日志 1Hz 抽样（14 samples/14s）正常（SDLOG 抽稀），别误判传感器故障
- QGC 默认可能显示 AMSL——**先问用户看的是 Rel 还是 AMSL 再下结论**（"一直 103.8m"第一嫌疑就是 AMSL 正常显示）
- 自稳模式高度不受控，EKF 高度失真不会自动拉回，显示跳变 = 纯显示问题，实际飞行要按 baro/目视判断
- 一键探查脚本：`scripts/altitude_source_probe.py <log.ulg>`
