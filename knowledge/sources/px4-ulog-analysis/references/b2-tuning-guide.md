# B2 飞控调参方案解析（用户文档 B2飞控调参.md，2026-08）

用户有一份 B2 飞控的调参笔记（桌面 `B2飞控调参/B2飞控调参.md`），用户明确说"看不懂调整频率的具体作用"。
本文件是对该方案的完整解析 + 与 ulg_report 指标/术语的映射，未来用户再问调参逻辑时直接引用。

## 整体思路（两步 + 顺序）
1. **先调滤波**（imu_DGyro_cutoff / imu_Gyro_cutoff）→ FFT 挑尖刺少的频率
2. **再调 PID**：内环角速度环（看延迟→加 D）→ 外环姿态环（看到位→加 P）
顺序不能反：滤波没调好（噪声大）→ D 项放大噪声 → 不敢加大增益 → 调参白费。
类比：戴模糊眼镜开车还怪方向盘不灵敏。

## 滤波频率（用户看不懂的核心）
### 低通滤波器截止频率
- 陀螺信号 = 真实姿态变化（低频，几~几十 Hz，有用）+ 电机/桨振动噪声（高频，几十~几百 Hz，有害）
- `imu_Gyro_cutoff` = 角速度主信号（P/I 用）的滤波截止频率
- `imu_DGyro_cutoff` = 角速度微分信号（D 项用）的滤波截止频率，**必须比 Gyro 小 10-30Hz**
- 类比：筛子。孔大（cutoff 高）→ 信息全但噪声也过；孔小 → 干净但真实信号被削+延迟
- cutoff 调高：响应快、延迟小，但振动噪声进；调低：干净但信号失真延迟大

### 为什么 DGyro cutoff 必须更小
**微分是噪声放大器**：微分在频域 = 乘以频率，60Hz 振动在角速度信号是 1 倍、微分后 60 倍。
D 通道必须先滤狠（更低 cutoff）压噪声，否则 D 输出全是高频"滋滋"抖动。

### FFT 选频率（B2 第一步）
- 尖刺 = 某频率存在强振动源（30-80Hz 电机转速基频、非整数倍=部件共振、全频底噪=电磁干扰）
- "前端"= 频谱低频段（0-150Hz 控制关心范围）；0Hz 附近凸起是真实姿态运动（正常）不是噪声
- 选尖刺小且少的 cutoff 档。测试矩阵：D/G = 30/40、50/60、60/70、60/80、60/90
- 逻辑：尖刺频率 < cutoff → 噪声漏进信号；尖刺 > cutoff → 已被滤除

### 滤波与 D 增益的配合（关键因果链）
滤波放宽（cutoff 高）→ D 项能加到更大而不抖；滤波收紧 → D 只能小。
B2 最终敢把 RATE_D 从 0.003 加到 0.009（3 倍），前提是 DGyro 滤波调到了 60Hz。

## PID 部分
### 角速度环（内环，看延迟）
- QGC Pitch/Roll Angular Rate 图：Setpoint vs Estimate 两曲线时间差 = 延迟
- **30ms 优秀 / 50ms 一般 / 70ms 差劲；延迟大 → 加 D**（D 看误差趋势提前预判出力，类比老司机提前松油门）
- B2 最终：RATE_P 0.15→0.5、RATE_D 0.003→0.009（P 给速度、D 给阻尼，经典配合）

### 姿态环（外环，看到位）
- Roll/Pitch Angle 图：期望 vs 实际能否到达同一值；达不到 → 加 P；100ms 内到位即可
- B2 最终：ROLL_P/PITCH_P 6.5→10.0

## 与 ulg_report 工具指标的映射
| B2 方案步骤 | ulg_report 对应 |
