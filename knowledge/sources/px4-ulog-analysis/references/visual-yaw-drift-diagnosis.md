本文件旧版（2026-08-18 上午沉淀）结论为"定点偏移根因 = 视觉 yaw 漂移污染 EKF"，**已被同日下午的用户反证推翻**。保留此文件名仅作误判教训存档，**不要按旧结论判案**。

## 误判经过（log 01_57_39，13s）
1. 初判：视觉 yaw 卡错 18°（76.8° vs 实际 58.2°）+ heading innovation 5.97 被拒 + yaw 扭矩 0.55 饱和 → 认定"视觉 yaw 漂移污染 EKF → 姿态环误纠偏 → 飞机被带转"
2. 用户反证①："之前定点没这问题"+"另一架同配置同场景没这问题" → 一定有东西变了
3. 再判：9.44s az=-15.6/ay=-9.7 加速度冲击 → 改判"撞障碍物"
4. 用户反证②："附近没有任何障碍物"
5. **最终实锤：机械振动/桨不平衡** —— 四电机 0.1s 内从均衡(0.33-0.40)变对角饱和(M3/M4→0)、姿态环 tq_z 0.55 打满拉不住且 yaw 指令方向与实测相反、振动分段 RMS 持续放大(ax 0.19→1.14→2.92, gyro 峰 123°/s)、imbalanced_prop_metric 27/27 全程非零、停桨后振动归零。**视觉 yaw 18° 偏差是机械振动导致 FAST-LIO 配准退化的症状，不是原因**

## 为什么旧结论错了（可复用教训）
- **"位置 innovation <1 + heading 被拒" 只能证明"EKF 认为位置融合健康、yaw 测量可疑"，不能区分"视觉源头漂移"还是"机身真在剧烈振动导致视觉退化"** —— 两者在 heading 被拒上表现相同
- **三源同步大转 ≠ 一定是"EKF 接受视觉漂移"**：机身物理真转（机械故障）时三源当然同步。必须加查**电机分配（对角饱和？）+ 振动分段（持续放大？）+ imbalanced_prop（全程报警？）+ 用户现场（有无障碍/另一架对比）**
- **用户反证 = 最高优先级证据**："之前没这问题"、"另一架同配置没事"、"没有障碍物"，出现任何一个都必须重查数据而非坚持结论
