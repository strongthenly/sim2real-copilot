# odin bag 双报告对比（交控方 vs 留形方）——"同等条件我方无问题"论证模板

## 触发条件
- 甲方/交控方给出 odin bag 分析报告（如"黑暗条件下悬停不稳/振荡"），我方在同等条件下复测无问题 → 要求合并成一份对比报告，科学证明我方无问题
- 2026-08-20 实例：`odin_bag_report（交控方）.pdf`（odin_new.bag，204.9s，检出 1.00Hz 振荡 81%、位置 std 3.463m）vs `bag_report(留形方).pdf`（2026-08-08 bag，280.5s，判定正常机动）→ `bag_对比分析报告（交控方_留形方）.pdf`（9 页）

## 关键前提：同一检测器，两种定性
1s RMS 滑窗只测运动活跃度——**对方数据检出"振荡"、我方数据同样检出高活跃（甚至占比更高 100% vs 81%）**，结论相反全靠证据链。这是对比报告的第一卖点：把两报告的运动段数字并排，证明差异不在数据而在定性。

## 报告结构（图随文走；用户 08-20 要求：**不留"报告说明/背景/目的"节，副标题也不要，标题后直接"1. 测试概况对比"**）
1. 测试概况对比表：文件/时间/时长/环境/提取话题/消息数/采样率——证明对比基础成立（对比公平性声明压缩成表格下方一句"点评"：同一套模板、同一阈值，差异=我方额外记录了摇杆/飞控/估计器话题）
2. 核心结论速览（TL;DR 表）：运动段检测 / 姿态主频 / 位置 std / 漂移范围 / 速度谱主峰 / 偏置警告 / 证据链有无
3. 量化指标对比总览（6 面板并排图：位置 std、主频、gyro RMS、位置包络、速度谱主峰、姿态 std）+ 读图要点
4. 逐项对比分析：IMU 质量 / 运动检测 / 频谱 / 高频振动 / Odometry 位置 / 姿态一致性——每项=表格+文字点评（好坏+原因+意义）
5. 证据链完整性对比（红绿"有/无"矩阵图）：摇杆 / 飞控模式 / EKF 有效性 / 姿态-加速度一致性 / 位置往返 / vision_pose 稳定性
6. 结论（我方正常，分点列证据）+ 建议表（给我方的维持项 + 给对方的核查项）
7. 附录：双方原始 6 面板图并排（pymupdf 抽 PDF 第 1 页图 + PIL 拼接）

## 四层科学论证结构
1. **同一检测器两种定性**：RMS 滑窗双方都检出高活跃 → 检测器区分不了机动 vs 故障，差别在证据链。对方 bag 缺 manual_control/state/estimator_status → 其"振荡"结论缺少可交叉验证的信息（基于检测器输出）
2. **量化差异**：位置 std 7 倍（3.463 vs 0.496 m）、对方 y 向漂移 8m vs 我方 ±2m 有界往返（与摇杆吻合）、主频 1.00Hz（超操纵频段）vs 0.39Hz（0.3-0.7Hz 正常频段）。**双方平稳段位置 std 都 ≈0.001m → 静止悬停都稳**，"悬停不稳"不成立
3. **对方数据自带线索**：对方报告自己检测出 gy 偏置 -2.9 deg/s 未补偿警告（积分漂移机理）、0.34Hz 慢漂成分、8m 位置漂移 → 指向其平台侧校准/估计问题，与"黑暗"无因果
4. **方法学自洽**：高频振动两报告结论一致（操纵响应非机械共振）= 我方方法可靠；**电机主频不同（25-34 vs 80-81 Hz）如实说明机型差异，对比用"平稳段 vs 运动段"相对比值消除机型影响**（绝对能量不可直接跨报告比，脚本实现可能不同）

## 附加论证点（黑暗环境专项）
- odin1 是 dToF LiDAR（主动光源）→ 定位本身不受光照条件影响，"黑暗导致定位不稳"在物理上不成立
- 姿态-加速度一致性（ax vs pitch, ay vs roll 相关 r>0.4）= 真实平动的运动学铁证，对方报告没做这项
- **matplotlib 微软雅黑缺 ↔ (U+2194) 字形 → 渲染成方框，图内一律用 "vs" 替代**（如 "ax vs pitch"）

## 措辞基调（用户 08-20 两轮纠正：减少双方强硬描述，数据差异表达完整清楚即可）
客观克制、数据说话、不攻击对方；**数据全部保留（7 倍、3.463/0.496、1.00/0.39、-2.9 deg/s、8 m、326×/374×、r=0.58/0.45、摇杆过零 10/20 次），只软化定性词**：

| 禁用 | 替换 |
|---|---|
| 关键差异 | 主要差异 |
| 隐患 / 铁证 / 分水岭 / 最硬的数据 | 特征 / 判据 / 频段归属不同 / 量级差异约 7 倍 |
| 属平台侧问题 / 与黑暗无因果关系 | 常见于控制环参数或状态估计层面的问题，建议结合平台进一步排查 |
| 缺乏证据链支撑 / 未经验证 | 缺少可交叉验证的信息 / 结论基于检测器输出 |
| 对抗语境中的"我方" | 留形方复测数据（中性指代） |

对对方报告用"其结论基于检测器输出/缺少可交叉验证的信息/建议排查"式表述，把己方证据链闭环立住即可。对方数据缺失的话题（摇杆等）在对比表中标"无"而非贬低。**交付前用 fitz 全文检查残留强硬词**（'隐患','铁证','分水岭','平台侧','未经验证','无因果关系','关键差异'）。

## 对比图硬性要求（用户 08-20 明确）
1. 每图标明数据来源方：颜色编码（交控方=红 #C0392B / 留形方=蓝 #2471A3）+ 图例 + xticklabels，图内直接标双方数值
2. 每图给对比结果：绿色结论条"对比结果：……"（数据差异 + 一句话结论）
3. 图紧跟对应章节表格（图随文走），编号与章节一一对应

## 图表布局防重叠（用户 08-20 明确："图标文字描述不要有重叠，影响观感"）
- **结论条放 figure 底部独立区**（不进轴内、不压刻度标签）：`fig.subplots_adjust(bottom=0.20~0.24, top=0.80)` + `fig.text(0.5, 0.125, "对比结果：……", ha="center", fontsize=9.5, color="#1E8449", fontweight="bold")` + 第二行 `fig.text(0.5, 0.075, ...)`
- 面板内只留 4-8 字短标注（"超出正常操纵频段"/"慢漂成分"/"正常频段内"），长解释放结论条或正文
- **annotate 长文本是最易重叠的元凶 → 用面板空白区短文本替代**（柱上方/柱右侧）
- 混合量纲（Hz/次数/deg/s）拆独立子图不共轴；图例/阈值线说明（如 r=0.4）放空白角落，与柱顶数值标注错开
- 位置包络图（矩形+文字）→ 文本放矩形内空白区，不与边框相交

## 流程要点
- 抽两份 PDF 文字：pymupdf `page.get_text()`（第 1 页常为纯图页，chars=0 正常）
- 抽图：`page.get_images(full=True)` → `fitz.Pixmap(doc, xref)`（n>4 转 csRGB）→ save
- 图表用 matplotlib（Microsoft YaHei 字体），对比色：甲方红 #C0392B / 我方蓝 #2471A3
- md → HTML 用 `merge_md_images_to_pdf_inline.py`（图随文走，非默认脚本的图全部前置）
- 验证：pypdf/fitz 读页数 + 每页 get_text 首行 + 关键数字关键词检查（如 '7 倍'、'0.39 Hz' 在全文）
