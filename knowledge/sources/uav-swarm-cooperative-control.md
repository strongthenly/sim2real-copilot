## 一、领域地图:4 个主题格(把书/论文往里归位)

集群控制的一切内容几乎都落在这 4 格里。读书时把每章往格子里塞,就不会散:

| 主题 | 回答什么问题 | 数学内核 |
|---|---|---|
| **一致性 / 编队** | N 个体如何收敛到同一状态 / 保持队形 | 图论(拉普拉斯 $L$、代数连通度 $\lambda_2$) + 一致性协议 |
| **集群行为(swarm)** | 如何涌现鸟群/鱼群式运动 | Reynolds 三规则(Boids)、Vicsek、势函数 |
| **任务分配 / 覆盖** | 谁去哪片、怎么不重复 | 拍卖/匈牙利、基于密度/信息增益 |
| **通信与鲁棒** | 谁连谁、断链掉队怎么办 | 代数连通度、事件触发、拓扑切换 |

判据:**"协同控制(cooperative control)"教材 = 偏前两格(控制论路线);"集群智能(swarm intelligence)"教材 = 偏第二格(仿生路线)。** 两者不是一回事,给用户定位时要先说清。

## 三、核心概念的标准解释(高频追问)

### "参考值对单个成员可以是未知的" = 分布式一致性跟踪
这是分布式协同最核心的思想。标准解释框架:
1. **先分两类**:①无领导一致性(收敛值由初值+拓扑自发涌现,没人预先知道);②一致性跟踪/领导-跟随(有参考值 $r$,希望全体趋于它)——"参考值对个体未知"说的是②。
2. **控制律**(讲"未知"就看 $b_i$):
   $$u_i = -\sum_{j\in\mathcal N_i} a_{ij}(x_i-x_j) - b_i(x_i-r)$$
   $b_i>0$=个体"知道"$r$; $b_i=0$=控制律里**不出现 $r$**,即"对我未知"。$b_i$ 精确对应"这个体知不知道参考值"。
3. **凭什么收敛**:靠**通信拓扑**把信息一跳一跳传过去。条件=**每个连通分量里至少有一个知道 $r$ 的成员**(有向图则是"以领导者为根的有向生成树")。哪怕只有 1 个成员知道,全群也收敛到 $r$。
4. **类比**:雁群(没人知道队形中心坐标)、排队过马路(只有排头知道去哪)、龙舟。
5. **价值**:省通信、抗单点故障、个体不需要全局信息/全局定位——**对无 GPS/依赖相对定位的 UAV 场景尤其有意义**。
6. **三种"未知"形态**:①钉扎/静态领导者(常数 $r$);②虚拟领导者/外系统(参考还在动,个体测不到→需**分布式观测器**);③完全无参考(leaderless)。
7. **前提/坑**:拓扑不满足生成树 → 分裂成几个小共识值(不到 $r$);参考在动时,收敛/跟踪快慢由 $-\!L$ 的谱($\lambda_2$)决定。

### 交互拓扑三矩阵:W / D / L(用户会问"各有什么作用、如何得到")
**先定死约定**:$w_{ij}>0 \iff$ 信息流 $j\to i$(行 = 接收者)。约定写乱会导致 $\xi$/根/共识值全错。
| 矩阵 | 从哪来 | 管什么 | 关键性质 |
|---|---|---|---|
| $W$ 加权邻接 | 通信/感知关系**直接给定** | "谁跟谁连、多强"(结构+权重) | 对称 $\Leftrightarrow$ 无向 |
| $D$ 入度矩阵 | $W$ 的**行和**(派生,不独立给):$D=\mathrm{diag}(W\mathbf 1)$ | 归一化分母;入/出度 | $d_i=\sum_j w_{ij}$ |
| $L=D-W$ | $D,W$ 算得 | **网络连通性/收敛性** | $L\mathbf 1=0$;"图→动态系统"的桥 |

- $L$ 性质(无向):对称半正定,$0=\lambda_1\le\lambda_2\le\dots$;**0 特征值重数 = 连通分量数**;$\lambda_2>0\iff$连通,$\lambda_2$=代数连通度=**一致性收敛速度**;二次型 $v^\top L v=\tfrac12\sum w_{ij}(v_i-v_j)^2$(→Lyapunov/能量)。
- $L$ 性质(有向):不对称;**含生成树 $\iff$ 0 单重**;左零特征向量 $\xi\ge0$($\xi^\top L=0$)决定共识值。
- **共识值**:无向连通 = 初值平均($\xi$ 均匀);有向含生成树 = $x_{\text{root}}(0)$(实测:入度为 0 的根恒定不动,其值传遍全群)。
- **如何得到**(工程建图流程):定节点 → 定边(通信半径) → 定方向 → 定权重(距离衰减/SNR/信任) → $D=\mathrm{diag}(W\mathbf 1)$ → $L=D-W$ → 算 $L$ 光谱判"收不收敛 / 多快 / 聚成几个"。
- 跑法:`scripts/graph_matrices.py`(无向 + 有向两个算例,直接跑出 W/D/L/特征值/ξ + 仿真印证)。

### 7 类代表问题的"一句话 + 目标集合"(详解见 references)
| 问题 | 一句话 | 目标集合 |
|---|---|---|
| 一致性 | 全体状态趋于同一值 | 一个点 $\{c\mathbf 1\}$ |
| 编队 | 一致性 + 期望偏移 $h$ | 仿射流形(形状) |
| 编队跟踪 | 编队整体跟踪时变参考 $r(t)$(需观测器) | 时变流形 |
| 合围 | 多领导者,跟随者进其凸包 | $\mathrm{conv}(\text{leaders})$ |
| 编队-合围 | 领导者自成编队 + 跟随者进其凸包(北航招牌) | 分层:流形 + 凸包 |
| 分布式优化 | 各人有 $f_i$,协同 $\min\sum f_i$(一致性只是手段) | $\arg\min\sum f_i$ |
| 分布式博弈 | 各人有 $J_i$,求纳什均衡(非合作) | 纳什均衡集 |

**递进主线**:几何台阶(点→流形→时变流形→凸集→分层凸集)+ 目的台阶(到达集合 → 求最优/均衡)。**两族**:状态约束族(协同控制)vs 最优性决策族(优化/博弈)。

### 控制律的"弹簧网 / 势能"直观(讲"为什么收敛"最好用)
$u_i=-\sum_j a_{ij}(x_i-x_j)-b_i(x_i-r)$ 是二次势能 $V=\tfrac12\sum_{i<j}a_{ij}\|x_i-x_j\|^2+\tfrac12\sum_i b_i\|x_i-r\|^2$ 的**负梯度** ⇒ 等价于"**邻居间连弹簧 + 锚点钉到 $r$**",整群沿势能最速下降停在其最小值。**无锚点的分量没有"地钉"→ 只能停在自己的重心**(与 $r$ 无关)。矩阵形式 $X'=-(L+B)X+B\mathbf 1 r^\top$,误差 $E=X-\mathbf 1 r^\top$ 满足 $\dot E=-(L+B)E$。**逐项/推广/误读的完整推导见 `references/cooperative-control-notes.md`**。

## 四、学习路径:理论配实践(与用户现有栈衔接)

**4 级台阶**(门槛从低到高):
| 台阶 | 做什么 | 用户现状 |
|---|---|---|
| ① 2D 质点仿真(Python) | 验证一致性/编队算法本身 | 秒级迭代的算法沙盒 |
| ② AirSim 多机 | 加真实四旋翼动力学+视觉 | ✅ 他 AirSim+UE4.27 已跑通单机,**原生支持多机**(settings.json 多 Vehicles + `MultirotorClient(vehicle_name=...)`) |
| ③ PX4 多机 SITL + Gazebo | 真实飞控栈+通信 | 有 WSL ROS2/Gazebo 底子(每架一个 offboard 端口 + `ROS_DOMAIN_ID` 隔离) |
| ④ 真机(≥3 架) | 协同 | 只有 1 架 fouruav |

**推荐起点 = ①+②**(摩擦最小),**别一上来上 ③**(多机 SITL 的坑会淹掉入门者)。

**按书章节配实践**(读一章配一个实验):一致性→Python 收敛;编队→3 机保三角;编队跟踪→编队沿轨迹飞;合围→2 领导者+3 跟随者进凸包;分布式优化→多机覆盖问题。

**补数学的最短顺序**:线性代数(矩阵特征值)→ 图论(邻接/度/拉普拉斯/连通度)→ 线性系统稳定性+Lyapunov → 凸优化基础。

## 六、绘图 / 数值坑(实测)

- **matplotlib 中文字体**:`rcParams['font.sans-serif']=["Microsoft YaHei","SimHei"]` + `axes.unicode_minus=False`。⚠️ **Microsoft YaHei 缺 `✓`(U+2713)/`✗`(U+2717)字形**→ 图上会出乱码方框;改用文字("收敛"/"不收敛")。`★`(U+2605) 正常。
- **离散一致性仿真稳定性**:`x(k+1)=x(k)-eps*(L x + diag(b)(x-r))`,需 `eps < 2/λmax(L+B)`(全连 5 节点时 `λmax≈6`,故 `eps=0.2` 安全)。
- **步数要够**:链式拓扑 `λ2=0.081` 很小,收敛慢——**实测 eps=0.2 时要 ~1000 步才收敛到参考值**(220 步会"看着像没收敛")。判"收敛到 r"看 `max‖x_i-r‖`;判"发散/分裂"看是否停在**各连通分量的局部共识值**。
- **演示脚本见 `scripts/consensus_demo.py`**(5 场景:链/环/全连/断开/无人知道 + 对比图 + 动画)。直接 `python scripts/consensus_demo.py` 即可产出,或复制后改 `R`/拓扑/`EPS`。
